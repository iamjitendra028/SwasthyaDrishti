# Project source alignment

The `Project Synopsis.pdf` and `SwasthyaDrishti_Sprint_Backlog_30_User_Stories.xlsx` both describe SwasthyaDrishti, a camera-supported sports, fitness, yoga and nutrition guidance system.

The current application is a web prototype. It includes the athlete-facing dashboard, module experiences, browser camera pose preview, sample nutrition recipes, and an optional local LangChain/Gemini API with Chroma retrieval. The sprint backlog also includes substantial work that is not implemented yet, including native mobile support, broader pose and movement analysis, validated coaching, athlete accounts, persistent profile/session databases, and coach/admin workflows.

The diagrams in `architecture.md` describe the planned system and implementation slices. They should not be read as evidence that the full sprint backlog is complete.
